## 一、基础语法与编码规范（PEP 8）

### 1.1 命名规范
- 变量 / 函数 / 方法 / 模块包：snake_case（小写 + 下划线）
- 类名：UpperCamelCase（大驼峰）
- 常量：UPPER_SNAKE_CASE（全大写）
- 私有属性 / 方法：_single_leading_underscore
- 特殊私有：__double_leading_underscore
- 避免使用：l、I、O、key、value、data、info、utils 等模糊命名

### 1.2 格式规范
- 缩进：4 个空格，禁止 Tab 与空格混用
- 行宽：≤ 120 字符
- 二元运算符两侧加空格
- 逗号后必须加空格
- 函数与类之间空两行
- 导入顺序：标准库 → 第三方库 → 本地包
- 禁止一行多语句：a=1;b=2
- 字符串优先使用双引号
- 避免行尾多余空格

### 1.3 关键字与保留字
不可用于变量名：False, None, True, and, as, assert, async, await, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield

### 1.4 注释规范
- 单行注释：# 后加空格
- 函数 / 类必须写文档字符串 docstring
- 复杂逻辑写注释，避免废话注释
- 不使用注释掉的旧代码

## 十五、常见 Bug 完整解决方案

### 15.1 IndentationError
- 原因：Tab 与空格混用、缩进不统一
- 方案：统一 4 空格，编辑器显示空白符

### 15.2 NameError
- 原因：变量未定义、拼写错误、作用域错误
- 方案：检查拼写、检查定义顺序、检查 global

### 15.3 TypeError
- 原因：类型不匹配、函数参数错误、不可变对象修改
- 方案：类型转换、检查参数、使用正确方法

### 15.4 ValueError
- 原因：值非法，如 int ("abc")
- 方案：校验输入、try-except、判断 isdigit

### 15.5 IndexError
- 原因：列表 / 字符串越界
- 方案：判断长度、避免硬编码索引

### 15.6 KeyError
- 原因：字典键不存在
- 方案：get ()、判断 key in d

### 15.7 AttributeError
- 原因：对象无属性 / 方法
- 方案：检查类型、检查初始化、检查拼写

### 15.8 UnboundLocalError
- 原因：函数内修改变量未声明 global
- 方案：加 global 或传参

### 15.9 FileNotFoundError
- 原因：路径错误、工作目录错误
- 方案：绝对路径、pathlib、检查文件

### 15.10 UnicodeDecodeError
- 原因：编码不匹配
- 方案：encoding='utf-8' 或 'gbk'

### 15.11 循环导入
- 原因：A 导入 B，B 导入 A
- 方案：抽离公共模块、延迟导入

### 15.12 默认参数为 [] / {}
- 原因：只初始化一次
- 方案：默认 None，函数内创建

### 15.13 列表遍历时删除
- 方案：倒序遍历、生成新列表、列表推导式

### 15.14 input 直接运算
- 方案：int (input ())、捕获异常

### 15.15 编码中文乱码
- 方案：文件 utf-8、open 指定编码、json ensure_ascii=False

### 15.16 浅拷贝问题
- 方案：copy / deepcopy
